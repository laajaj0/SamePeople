# SamePeople 🌍

**An Open-Source Platform for Meaningful Global Connections**

SamePeople is an open-source project aiming to connect people worldwide through meaningful friendships and relationships, with a focus on compatibility, privacy, trust, and user safety.

## 🎯 Vision

Build a modern, secure, and inclusive platform where people can discover compatible individuals, communicate, and build meaningful connections regardless of geographical boundaries.

## 🛠️ Planned Technology Stack

- Frontend: Angular
- Backend: Java & Spring Boot
- Database: PostgreSQL
- Authentication: Spring Security & JWT
- API: RESTful API
- Infrastructure: Docker
- CI/CD: GitHub Actions

## 🚀 Planned Core Features

- User registration and authentication
- User profiles and profile preferences
- Discover and match compatible people
- Friendship and relationship preferences
- Real-time messaging
- Privacy and account settings
- User blocking and reporting
- Security and moderation mechanisms

## 🏗️ Project Status

**Status: Initial Setup / Planning**

SamePeople is currently in its initial development stage. Its architecture, requirements, and implementation roadmap are being established.
